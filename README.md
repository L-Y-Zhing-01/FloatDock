# 浮坞 FloatDock

一个 Windows 悬浮窗口容器。把任意程序窗口「拖」进浮坞，它就在面板里继续用；
鼠标移开自动隐藏，双击标题栏或按热键唤回，释放时窗口原样回到桌面。

> A floating dock for Windows: drag any window into the panel, keep using it there,
> and get it back untouched on release. No Python, no runtime, no network needed.

## 它解决什么问题

双屏、超大屏或只有一台笔记本的时候，总有几个窗口需要「随手就在、不挡路」：
参考资料、待办列表、聊天窗口、监控面板。开成浮动小窗会互相压住，最小化又
等于关掉。浮坞把**一个真实窗口**整体搬进自己的面板，原程序照常响应键盘鼠标，
用完释放，位置与样式逐位还原。

与「窗口置顶 / 分组 / 虚拟桌面」的区别：浮坞给的是一个**固定容器**，宽度高度
由你拖，内容区随之缩放，隐藏时整个面板从屏幕上消失，不留感应带。

## 功能

| 功能 | 说明 |
|---|---|
| 悬停显隐 | 鼠标移开面板约 0.05 秒自动隐藏（可调到 0.3 秒），双击标题栏或全局热键唤回 |
| 拖拽吸附 | 按住标题栏左端的 ✥ 拖到目标窗口上，出现红框松手即吸附 |
| 原样释放 | 点 ⤴ 释放，窗口回到原位置、原尺寸、原样式（含最大化 / 最小化状态） |
| 单窗口容器 | 一次只放一个窗口，换目标时自动释放旧的（首次会确认，可勾「以后不再提醒」） |
| 自由缩放 | 四条边、四个角都可拖拽（边缘 5px / 角部 11px 感应区） |
| 透明度 | 点 ◐ 弹滑块，或滚轮悬停标题栏滚动，35%–100% |
| 锁定常显 | 点 🔒 不再自动隐藏，适合长文档 |
| 全局热键 | 默认 `Ctrl+Alt+D`；支持 A–Z / 0–9 / F1–F24 / 小键盘，功能键可单独使用 |
| 按钮提示 | 鼠标在标题栏按钮上停 0.38 秒，下方弹出一句话说明 |
| 托盘控制 | 右键菜单：显示/隐藏、锁定、释放、设置、赞赏、关于、退出 |
| 赞赏支持 | 标题栏 ♥ 显示赞赏码，**完全自愿，不影响任何功能** |

## 系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11，64 位 |
| Python | **不需要**（解释器与 Tcl/Tk 随安装包携带） |
| VC++ 运行库 | **不需要**（`VCRUNTIME140.dll` 随包携带） |
| 管理员权限 | **不需要**（清单为 `asInvoker`，可装到用户目录） |
| 网络 | **不需要**（程序自身没有任何网络请求；只有「关于」框的「打开源码页」按钮会调起系统浏览器） |

安装包约 34 MB（含 Python 解释器与 Tcl/Tk），装完约 30 MB；源码版解压即用。

## 下载与安装

从 [Releases](https://github.com/L-Y-Zhing-01/FloatDock/releases) 下载
`浮坞-FloatDock-<版本>-安装程序.exe`，双击按向导安装：

- 可选安装位置（默认 `%LOCALAPPDATA%\Programs\FloatDock`）
- 可选桌面 / 开始菜单快捷方式、开机自启
- 设置保存在 `%LOCALAPPDATA%\FloatDock\config.json`，与安装目录分离

卸载：系统「设置 → 应用」里找「浮坞 FloatDock」，或运行安装目录里的
「卸载程序.exe」，可选保留设置。

静默参数（批量部署）：安装程序 `/S`、`/D=目录`、`/NODESKTOP`、`/NOSTARTUP`、
`/AUTORUN`；卸载程序 `/S`、`/KEEPCONFIG`。

## 基本操作

| 想做什么 | 怎么做 |
|---|---|
| 唤出面板 | 全局热键 / 单击托盘图标 / 托盘右键「显示 / 隐藏浮坞」 |
| 吸附窗口 | 按住标题栏 ✥ 拖到目标窗口上（出现红框）松开 |
| 隐藏面板 | 鼠标移开 / 双击标题栏 / 再按一次热键 |
| 改变大小 | 拖四条边或四个角 |
| 移动面板 | 拖标题栏空白处 |
| 换一个窗口 | 先释放当前窗口再吸新的，或直接吸（首次会确认） |
| 释放窗口 | 点 ⤴ |
| 锁定常显 | 点 🔒 |
| 设置热键 | 点 ⚙，点「按键」框后**直接按组合键**，回车生效 |
| 退出 | 标题栏 ✕ 或托盘「退出」（都会先释放吸附的窗口） |

## 从源码运行

需要 Python 3.10+ 与 tkinter（官方安装包默认包含）：

```bat
python floatdock.pyw          :: 无控制台窗口
python floatdock.pyw --debug  :: 带日志，输出到 debug.log 与 stderr
```

指定配置文件（默认是程序目录下的 `config.json`）：

```bat
python floatdock.pyw --config "%LOCALAPPDATA%\FloatDock\config.json"
```

源码树里没有第三方依赖，装好 Python 就能跑。

## 开发

```bat
python tests\run_all.py        :: 全部回归
python tests\test_units.py     :: 单个文件
python installer\build.py all  :: 构建安装程序（需 PyInstaller）
python tools\make_archive.py   :: 打源码归档 zip（会自动对账三处版本号）
```

测试直接创建真实窗口并注入鼠标键盘事件，不是 mock；部分用例需要交互式
桌面会话（在无桌面的服务会话里会跳过抓屏相关断言）。

## 已知限制

- 只能吸附**顶层窗口**，不能吸附以管理员权限运行的程序（除非浮坞也以管理员运行）。
- 部分 UWP / 自绘窗口吸附后布局可能异常，释放后仍可还原。
- 面板与吸附的窗口是父子关系，被吸附窗口的快捷键在浮坞内照常生效，
  但它的系统菜单（Alt+空格）会被容器接管。
- 一次只容纳一个窗口。
